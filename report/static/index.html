降低前缀 KV
回载的尾延迟

Agent 会话从存储回载前缀时，高回载量请求可能阻塞后到的低回载量请求。SuperLoad 用同一个调度器安排存储读取和 H2D 拷贝，让后到请求在两个阶段都能优先推进。

SuperLoad 如何协调两阶段回载

同一调度器跟踪各请求的待回载 KV 页、目标 HBM 地址和搬运进度。每次提交存储读取或 H2D 拷贝时，由它选择下一块要搬运的 KV。
