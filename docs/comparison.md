# Agent 前缀回载方法对照

实验比较应用层队列、文件布局与传输粒度对大小回载争用的影响。现象验证与缓存敏感性见 [前缀回载争用](prefix-reload.md)。

## 负载和到达条件

从 23,608 条 Mooncake Tool & Agent 请求生成回放。HBM、DRAM、存储层的模拟 KV 预算分别为 8、16、64 GiB，前 100 个时间窗用于预热。先用相同的 LRU 模型得到存储命中但 HBM、DRAM 缺失的页，再在 232 个同窗大小回载候选中随机抽取 24 对。小回载为 8–32 MiB，大回载至少 128 MiB。当前模型与配置下，测量窗内的存储回载页未出现跨请求共享。公开时戳的分辨率约为 3 秒，组内细粒度顺序由实验控制。[轨迹与字段](https://github.com/kvcache-ai/Mooncake/tree/main/FAST25-release)

每对在两种条件下回放。第一种同时到达，FIFO 平局时先入队大回载。第二种大回载早到 25 ms，模型中的小回载可以在通路正忙时到达。五种方法使用相同的页、字节和到达时刻。合成文件按抽样页号紧凑存放，读合并收益取决于实际部署的文件布局。两种 I/O 模式均重复两轮，Buffered 测全部 24 对，Direct 测从中抽取的 20 对。轮内打乱请求对的顺序，并随机化每对的十个条件。Buffered 对两种文件布局先做预读，Direct I/O 绕过工作区客户端页缓存。

## 方法

| 方法 | 测量实现 |
| --- | --- |
| 原生 FIFO | 按到达顺序整请求读取，文件使用 layer-major 布局。完成同步 H2D 后再处理下一请求。 |
| Bidaw | 已知存储缺页量，用等待时间除以回载块数决定待服务请求的 Disk-HRRN 优先级。缓存模型固定，测量范围为论文的存储队列排序。 [论文 §3.2](https://www.usenix.org/system/files/fast26-hu-shipeng.pdf) |
| Strata I/O | 使用 page-first 布局，按文件页位置排序并合并相邻读，按 FIFO 处理。共享页和模型批调度需要相应的工作负载。 [论文](https://www.usenix.org/conference/osdi26/presentation/xie-zhiqiang) |
| Libra 流水 | 保留 FIFO，在请求内切成 16 MiB 块，两个 DRAM 缓冲交替工作。将论文的计算与跨实例 KV 传输流水移植到本机读文件和 H2D 两阶段。主线程拷入当前块，读线程并行读下一块。 [论文 §4.3](https://www.usenix.org/system/files/nsdi26-ruan-libra.pdf) |
| 固定分块轮转 | 使用与 Libra 相同的 16 MiB 块。每一块同步读入 DRAM 并拷入 HBM，然后在排队请求间轮转。在块结束时接纳本块执行期间到达的请求。 |

## 指标和解释范围

每对由同一逻辑 NPU 上的 AscendCL 写入 HBM。第一轮逐对逐条件回读大小请求的首末块，第二轮每个条件复核一对。文件 I/O、同步 H2D、排队与流水重叠分别计时。字节检查位于计时区间外。

每轮按最近秩法计算小、大回载的 HBM 就绪 P95，报告各轮中位数并展示单轮值。吞吐使用两项请求都完成之前的累计窗口耗时和实际写入 HBM 字节。排队时延截止到请求首次获得工作线程，固定分块轮转中后续的等待计入就绪时延。流水重叠以相邻块的读阶段和 H2D 调用的时间交集计算。

实验只回放这条数据通路。小回载以受控时差到达，模型计算、在线请求批处理和生产毫秒级到达顺序属于后续服务端评估范围。不同 I/O 模式的样本数略有差异，方案对比以同一模式内的配对结果为准。

## 实测结果

大回载早到 25 ms 时，各轮指标中位数如下。

| 方法 | Buffered 小回载 P95（ms） | Buffered 吞吐（GiB/s） | Direct 小回载 P95（ms） | Direct 大回载 P95（ms） | Direct 吞吐（GiB/s） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原生 FIFO | 1,201 | 0.533 | 4,014 | 3,916 | 0.124 |
| Bidaw | 1,191 | 0.552 | 3,956 | 3,887 | 0.124 |
| Strata I/O | 1,242 | 0.567 | 1,529 | 1,489 | 0.303 |
| Libra 流水 | 1,229 | 0.840 | 3,490 | 3,383 | 0.155 |
| 固定分块轮转 | 116 | 0.602 | 549 | 4,775 | 0.112 |

- **待发请求排序**。同时到达时，Bidaw 将 Direct 小回载 P95 从 3,914 ms 降到 264 ms。大回载先占用加载器时，Bidaw 只能排序尚未开始的请求。
- **读合并**。Strata I/O 在 Direct 下将每对请求的平均读调用从 332.8 次降到 3.7 次，并同时降低大小回载的 P95。Buffered 下的 P95 变化有限。
- **流水重叠**。大回载早到时，Libra 在 Buffered 和 Direct 下分别将吞吐提高到 0.840 和 0.155 GiB/s。Direct 大回载的读阶段与 H2D 重叠时间中位数为 336 ms。请求级 FIFO 下，小回载仍需等待大回载结束。
- **块边界轮转**。大回载早到时，轮转给小回载最短的就绪 P95。Direct 下同时观察到大回载 P95 从 3,916 ms 增至 4,775 ms，双请求吞吐从 0.124 降至 0.112 GiB/s。
