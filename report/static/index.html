复现实验

使用公开 Mooncake 请求轨迹生成回载测量计划，在 Linux 和 Ascend CANN 环境下运行。

curl -fLo toolagent_trace.jsonl https://raw.githubusercontent.com/kvcache-ai/Mooncake/main/FAST25-release/traces/toolagent_trace.jsonl
source /usr/local/Ascend/ascend-toolkit/set_env.sh
python3 -m superload prefix-plan --trace toolagent_trace.jsonl --output runs/prefix/plan.json
python3 -m superload prefix-bench --plan runs/prefix/plan.json --corpus data/prefix \
  --io buffered --storage-label longhorn-ext4 --output runs/prefix/buffered.json
python3 -m superload prefix-bench --plan runs/prefix/plan.json --corpus data/prefix \
  --io direct --repeat 2 --pair-limit 16 --storage-label longhorn-ext4 --output runs/prefix/direct.json

五种方案

原生加载

实测基线

layer-major 文件通过 preadv 读入对齐主机缓冲，随后 aclrtMemcpy 同步拷到 HBM。记录文件读取、缓冲整理和 H2D 耗时。

RoCE RC 中转

同节点回环实测

存储进程读文件，经 libibverbs RC SEND/RECV 把 KV 传入客户端 DRAM，再用 AscendCL 拷入 HBM。两进程使用同一 mlx5 网口和 32 KiB 注册窗口。TCP 控制通道只交换页号和控制信息。RoCE 数据路径

Strata

OSDI ’26

复现 page-first 布局与批内前缀共享。相邻页发成一次文件读。同批并发请求共享已加载的 HBM 页。把布局和共享拆开对照。正式论文

Bidaw

FAST ’26

同批先服务全 DRAM 命中请求，再按缺页字节数排序。用已完成批次的合成回复长度及复用距离估计淘汰优先级。Bidaw 和等容量 LRU 已按修正后的时序成对重测。正式论文

SolidAttention

FAST ’26

按 token 交织 K/V，每层连续读出 K 和 V。稀疏解码用上一步的动态选择启动后台读，回放时补齐未命中的页。未被消费的预取计入文件 I/O。正式论文

复现早期机制实验

语料固定为 192 页，每页 2 MiB。使用 4 层 GQA 的 BF16 字节形状，索引和 payload 可用固定种子重建。

source /usr/local/Ascend/ascend-toolkit/set_env.sh
python3 -m superload build-corpus data/kv
cmake -S native -B build/native
cmake --build build/native
for f in data/kv/*.bin; do cat "$f" >/dev/null; done
python3 scripts/run_matrix.py --corpus data/kv \
  --roce --io buffered --waves 32 --run-label buffered-primary-roce \
  --output runs/buffered
